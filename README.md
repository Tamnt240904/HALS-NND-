# HALS-NND-

## Bước 1: Cài uv
```bash
pip install uv
```

## Bước 2: 
Nếu chưa clone
```bash
git clone https://github.com/Tamnt240904/HALS-NND-.git
cd HALS-NND-
```
Nếu muốn pull 

```bash
git config --global pull.rebase false
```

## Bước 3: Kích hoạt uv venv
```bash
uv sync 
```
Với Linux:
```bash
source .venv/bin/activate
```

Với Window:
```bash
.venv\Scripts\activate
```
